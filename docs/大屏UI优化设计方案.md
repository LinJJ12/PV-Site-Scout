# 光伏电站智能选址大屏 · UI 升级设计方案

> 版本 v1.0 · 2026-10-05 · 配套视觉稿：`npm run dev` 后访问 <http://127.0.0.1:5173/design/mockup.html>

## 一、现状诊断（基于 1920×1080 实测截图）

对三个页签逐一走查后，问题按严重程度排序：

| # | 问题 | 证据 | 影响 |
|---|------|------|------|
| 1 | **中心地图"有形无数据"** | 全国地图单色青绿，省份未按任何指标着色，无点位、无热力、无飞线 | 大屏最核心的主视觉没有承担数据叙事，1.16 万站点数据完全不可见 |
| 2 | **背景特效堆叠，视觉噪音大** | `styles.css` 同时运行 5 层动画（网格漂移/极光/扫描线/浮块/条纹），透明度最高 0.86 | "科技感"靠贴纸式特效堆出来，反而显廉价；数据被背景抢戏 |
| 3 | **图表是"报表风"而非"大屏风"** | ECharts 默认轴线/图例/tooltip 未做主题化；首页雷达图渲染空白（bug）；散点图 x 轴名称被裁剪（"G…"） | 精细度不足是"高级感"差距的最大来源 |
| 4 | **布局溢出与失衡** | 首页左下"各等级选址占比"进度条列表溢出面板压到地图上；右上蜂窝块留白严重；实时选址页右栏 2/3 空白 | 显得未完成 |
| 5 | **数字无仪式感** | KPI 用微软雅黑直接显示，无 count-up、无数字字体 | 大屏惯例是 DIN 类数字字体 + 滚动动画，这是"第一眼高级感"的关键 |
| 6 | **数据口径不一致** | 静态数据 PVPI 为 0~100 分（均值 28.41），实时预测 PVPI 为 0~0.95（分级阈值 0.8/0.6/0.4）；"约束区"颜色一处橙 `#ff8b38` 一处红 `#ff6b6b` | 同屏出现两个 PVPI 口径会直接损害可信度 |
| 7 | **无屏幕自适配** | `body { min-width: 1180px; overflow: hidden }`，非 16:9 或低分屏直接裁切 | 大屏标配是 1920×1080 设计稿等比缩放 |
| 8 | **图表零联动** | 点击省份只影响地图自身，右侧榜单/图表不跟随过滤 | "联动"是指挥大屏的基本特征 |
| 9 | **数据利用率低** | 1.16 万站点只用于 TOP10 表格和省级聚合；省均 PVPI 排行、GHI×PVPI 散点等已算出的信息呈现平淡 | 花了大力气算的 MCDM 评分没有视觉回报 |

**值得保留的优点**：Three.js 省级下钻（市域边界 + 光柱）已可用；GSAP 相机动画顺滑；数据管线（`sync-data.mjs` 自动从 backend 同步真实数据）设计正确。升级应在此基础上换"皮"强"骨"，而非推倒重来。

## 二、设计定位与参考

**一句话定位**：从"特效堆叠的科技风网页"升级为"**数据驱动、克制精致的专业指挥大屏**"。

高级感的三个来源（按优先级）：

1. **数据密度与叙事** —— 地图会说话（着色/点位/飞线），一眼看出"哪里适合建站"；
2. **统一的设计系统** —— 一套色板、一种面板、一套数字字体贯穿全屏，而不是每个面板各写各的；
3. **克制的动效** —— 动效只出现在"数据"上（数字滚动、光柱呼吸、飞线流动），背景安静。

参考对象：[阿里云 DataV 设计库](https://datav.aliyun.com)（区域热力层/呼吸点/飞线的官方范式）、[DataV 开源组件库](http://datav.jiaminghi.com)（边框装饰/翻牌器/飞线图组件）、[iDataV 开源案例](https://github.com/yyhsong/iDataV)（ECharts Geo 大屏布局）；深色数据界面遵循 2025 通行的 [Dark Mode 数据大屏最佳实践](https://www.qodequay.com)：用深蓝灰而非纯黑、去饱和强调色、远距离可读的大字号数字、首屏 KPI 不超过 6 个。

## 三、设计系统（Design Tokens）

### 3.1 色板

```
背景层次      #050D1F → #0A1730（深海军蓝，禁止纯黑）
             面板底：rgba(13, 34, 64, 0.55) + 1px 渐变描边 rgba(0,212,254,.28)
主色·科技青   #00D4FE   （主系列、地图高值、链接、焦点）
深空蓝        #1560BD   （地图中值、次系列）
语义四级（全站统一：地图/饼图/表格徽标/实时结果徽标共用）
  优选区  #00FFA3   适宜区  #00D4FE   备选区  #FFC53D   约束区  #FF6B6B
地图色带（choropleth，按省均 PVPI 由低到高）
  #0A2B52 → #0E4B8F → #0F79C7 → #00D4FE → #7DF0FF
文本        主 #E6F4FF / 次 #8FB3D9 / 弱 #5A7CA6
```

规则：一屏主色不超过 1 种 + 语义色 4 种；所有发光（box-shadow/glow）只用于数据元素，不用于容器。

### 3.2 字体

| 用途 | 字体 | 规格 |
|------|------|------|
| 数字/时间（KPI、坐标、表格数值） | `Bahnschrift`（Win10+ 自带，DIN 1451 同源，零成本）→ `DIN Alternate` → `Segoe UI` | KPI 40~44px SemiBold；`font-variant-numeric: tabular-nums` |
| 中文标题 | `Microsoft YaHei` Bold | 面板标题 15~16px，字距 +2px |
| 正文/轴标签 | `Microsoft YaHei` | 12~13px |

### 3.3 面板组件（PanelCard，全站唯一实现）

```
┌─ ◈ 面板标题 ────────────── 单位/说明 ─┐   ← 标题左侧 6px 发光短杠 + 菱形饰件
│ ╲                                    ╱ │   ← 四角 8px 亮色角饰（::before/::after）
│         内容区（12px 内边距）            │   ← 底 rgba(13,34,64,.55) + backdrop-blur(4px)
└─ ╲                                  ╱ ─┘
```

用 Vue 单组件替代现状 6 种手写面板标题；四角饰件 + 顶部渐变描边是"大屏感"最低成本、最高回报的一笔。

### 3.4 屏幕自适配（大屏标配）

设计稿锁定 **1920×1080**，运行时 `transform: scale()` 等比缩放（约 30 行 composable）：

```js

```

替换现有 `min-width + overflow:hidden` 方案，任何屏幕不变形不裁切。

```
├──────────────┬──────────────────────────────────────┬──────────────────┤
│ 各等级占比    │                                      │ 资源画像（雷达）    │
│ 环图+中心总数 │        中国地图（choropleth）          │  5 维全国均值      │
│──────────────│      省份按 PVPI 着色                  │──────────────────│
```

```
├──────────────────────────────────────────┬─────────────────────────┤

│  点击气泡 → 右卡 + 左下条形高亮该省          │ 选中省份 5 指标          │
├──────────────────────┬───────────────────┤ + 等级徽标 + 迷你趋势      │
│ 装机潜力排行（条形）    │ 等级结构（环图）    ├─────────────────────────┤
├──────────────────────┴───────────────────┤ TOP10 榜单（自动滚动）     │
└──────────────────────────────────────────┴─────────────────────────┘
```

语义修正：现状"省域平均潜力趋势"x 轴是省份不是时间，应更名为"省域 PVPI 对比"；"K线"实为 PVPI 四分位箱线图，标题改为"省域 PVPI 分布（箱线）"。

## 五、地图升级方案（核心主视觉）

按投入产出排序，全部在现有 Three.js 组件或 ECharts geo 上实现：

| 层 | 方案 | 实现要点 |
|----|------|---------|
| ① 省域着色 | 省均 PVPI choropleth，`visualMap` 连续色带 | ECharts geo 一行注册 `registerMap('china', geojson)`；Three.js 方案则按 `getGeoBaseColor` 改为读取 PVPI 映射色 |
| ② 点位层 | TOP 400 站点呼吸光柱（全国视图即显示，不再只在省级下钻显示） | Three.js `InstancedMesh` 一次绘制 400 柱，`sin(t)` 呼吸；或 ECharts `effectScatter` |
| ③ 底座辉光 | 地图下方椭圆渐变光晕 + 缓慢旋转的外圈扫描环 | CSS radial-gradient + conic-gradient 蒙版，或 Three.js 平面贴图 |
| ④ 飞线 | PVPI TOP5 省会 → 全国最优站点（宁夏）弧线飞线 | ECharts `lines` + `effect.trailLength`；Three.js 用 QuadraticBezierCurve3 + dash 流动 |
| ⑤ 密度热力 | 全国视图可选切换"密度热力"模式（1.16 万点 heatmap） | ECharts heatmap + bmap/geo；默认关、作为大屏第二画面轮播 |
| ⑥ 联动 | 点击省份 → 右栏榜单/雷达过滤到该省，顶部出现"省份 ▾ 返回全国"面包屑 | 现有 `province-focus` 事件已具备，接一个共享 store 即可 |

主视觉升级后，首页地图从"装饰"变为"结论"：西北深色高值区 + 密集光柱直接回答"哪里适合建站"。

**实现参照（threemap 的图层化结构）**：P2 按 `核心类 + utils/drawXxx` 的模式渐进重构 ThreeChinaMap——`drawDistrict`（顶/侧面独立配色 + 按 PVPI range 映射渐变，替代现在按经纬度调色的 `getGeoBaseColor`）、`drawCylinder`（光柱高度按 PVPI 映射 min/maxHeight，InstancedMesh 化）、`drawFlight`（弧线 + 头部粒子飞线）、`drawFoundation`（底座）、`drawLabel`（现有 HTML 标签层已等价于 CSS2D，保留）。选择性 Bloom（`drawGlow` + `_isGlow` 标记）作为可选项，先测帧率再决定是否启用；默认用贴图/阴影假辉光兜底。

## 六、ECharts 大屏主题（一次性注册，全站生效）

```js
// theme/bigscreen.js —— registerTheme('bigscreen', {...}) 后所有 setOption 只传数据
{
  backgroundColor: 'transparent',

  series-bar: 渐变 #0E4B8F→#00D4FE + 顶部圆角 + 数值标签，

```

同时把 App.vue 中 6 个 `renderXxx` 函数收敛为 `composables/useChart.js`（init/resize/dispose/主题一次管理，替换现状"全量 dispose 再重建"的写法）。

## 七、动效规范（做减法）

| 位置 | 效果 | 参数 |
|------|------|------|
| 背景 | **删除现有 5 层动画中的 4 层**，保留静态星点网格（透明度 ≤8%）+ 1 条 8s 扫描光带 | opacity ≤ .15 |
| 入场 | 面板自下而上 stagger 浮现（GSAP） | 300ms × 80ms 间隔，仅首次 |
| KPI | 数字 count-up 滚动 | 1.2s ease-out，千分位 |
| 地图 | 光柱呼吸、飞线拖尾、扫描环旋转 | sin 周期 2~3s |
| 榜单 | TOP10 无缝向上滚动 | CSS keyframes，hover 暂停 |
| 加载 | 开场 Loading：logo + 进度条 + "正在接入真实数据" | 数据就绪后 400ms 淡出 |

原则：同一时刻运动的元素 ≤ 3 处；所有动画 ≤ 2s 内结束（呼吸类循环除外）。

## 八、技术实施

**栈不变**：Vue3 + Vite + ECharts + Three.js + GSAP。不引入图表库/组件库——现有栈能力已覆盖全部需求，引入 DataV 组件库反而会带来第二套图表体系与风格冲突；只借鉴其边框装饰与飞线的实现样式手写。

**目录规划**（App.vue 从 1196 行拆分）：

```
frontend/src/
├─ styles/
│  ├─ tokens.css          # 3.1/3.2 全部变量
│  └─ base.css            # 背景、滚动条、公共工具类
├─ theme/bigscreen.js     # ECharts 主题注册
├─ composables/
│  ├─ useChart.js         # 图表生命周期 + resize
│  ├─ useFitScreen.js     # 等比缩放
│  └─ useCountUp.js
├─ components/
│  ├─ PanelCard.vue       # 3.3 统一面板
│  ├─ KpiFlipBar.vue      # 顶部翻牌条
│  ├─ RankBars.vue        # 省域梯队条形
│  ├─ AutoScrollTable.vue # TOP10 滚动榜
│  ├─ ThreeChinaMap.vue   # 保留，按 §五 增强
│  └─ panels/…            # 各页签面板
```

性能护栏：3D 光柱 `InstancedMesh`；全国点位抽稀至 ≤1200；ECharts 按需引入 `echarts/core`；保持现有 `pixelRatio ≤ 1.5`。
